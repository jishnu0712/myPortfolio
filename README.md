# Jishnu Dev Roy - Portfolio

Personal portfolio site built with React 19, Vite 5, and Tailwind CSS 3.4.

## Getting Started

```bash
npm install
npm run dev
```

Opens at [http://localhost:5173](http://localhost:5173).

## Scripts

| Command            | Description                          |
|--------------------|--------------------------------------|
| `npm run dev`      | Start development server             |
| `npm run build`    | Production build (output in `dist/`) |
| `npm run preview`  | Preview the production build         |
| `npm run deploy`   | Build and deploy to GitHub Pages     |

## Tech Stack

- **React 19** with React Router 7
- **Vite 5** for fast development and builds
- **Tailwind CSS 3.4** for utility-first styling
- **Font Awesome 6** for icons

## Environment Variables

Create a `.env` file in the root:

```
VITE_SUB_HEADLINE="I am a Software Developer"
VITE_TECH_STACKS="JavaScript, React.js, Node.js, ..."
```
